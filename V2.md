Chiffres : **0 `!important`**, 0 `catch` vide, 0 variable globale, 0 `window.__`, 9 fichiers JS de socle (≈ 800 lignes) contre 61 scripts / 885 fonctions / 228 `catch` / 717 `!important` avant.

### Règles du socle
- Seul `state.modifier()` change l'état ; il planifie l'écriture et annonce `etat:modifie`.
- Un module n'en appelle pas un autre pour « prévenir » : il fait `emit("repas:note", …)`. Les noms valides sont dans `events.js` (`NOMS`) ; un nom inconnu est signalé dans le journal.
- Toute erreur attrapée passe par `journal.erreur(ou, e)`. Lisible dans Moi > Bilan > Données (brique 4).
- Style : variables de `tokens.css` uniquement ; un nouveau style va dans la feuille de son écran ; jamais de `!important`, jamais de passe « finitions » après rendu.
- Pas de build : `index.html` charge `src/main.js` en module. GitHub Pages sert les fichiers tels quels. Test local : `python3 -m http.server`.

Décisions proposées (dis-moi si tu veux autre chose) :
1. **Pas d'outil de build** : modules ES natifs. (Pas d'accès réseau ici pour installer un bundler, et ce n'est pas nécessaire.) `index.html` n'est plus généré.
2. **4 angles = regroupement à l'affichage** des 8 jauges (Corps, Esprit, Liens, Foyer ; `ANGLES` existe déjà), **sans migration** des données : l'XP par catégorie reste dans `S.stats`.
3. **Coffre à 5 crans** : nouvelle clé `S.g.coffre` `{jour, n}` ; l'ancien coffre `chests/opened` est gardé tel quel. 1 repas, 1 routine ou 1 quête spéciale = +1 cran ; 5/5 = coffre garanti, avec l'événement `coffre:pret`.
4. **Courbe sociale ralentie** : un coefficient appliqué au calcul des paliers de liens, **sans réécrire `S.bonds`** (le lien déjà gagné ne change pas, les paliers s'étalent sur plusieurs mois).
5. **Roulette des proches** : tirage pondéré par l'ancienneté du dernier contact (`bondsLast`/`rel`), jamais deux fois la même personne d'affilée ; nouvelle clé `S.g.roulette`.
6. `parcours.py` et `centrage.py` de `_legacy/outils/` visent l'ancienne interface : ils seront **réécrits** pour la V2 (brique 5), pas adaptés.
7. Les règles de `CLAUDE.md` sur l'accent « or `#ffd94a` » sont périmées (Cobalt = orange `#ff6a2b`) : mises à jour dans ce dépôt.

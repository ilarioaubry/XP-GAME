# Fonctionnalités d'XP

État au 25/10/2026, après le tri de la phase 2. Une fonctionnalité retirée est **supprimée du code**, jamais seulement cachée (règle dans CLAUDE.md).

Statut : **active** · **module** = désactivable dans Moi > Ma vie > Mes modules · **moment** = n'apparaît qu'à un moment précis · **saison** = décembre / janvier.
XP : barème (petite action 2–5, repas / rituel ~10, quête 15–30). « ? » = à vérifier.
